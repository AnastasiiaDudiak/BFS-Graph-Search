# BFS-Graph-Search
# Дослідження алгоритму пошуку в ширину (BFS)

Лабораторна робота на тему:
«Сліпий пошук на графах. Особливості реалізації пошуку в ширину у графах».

Програма реалізує алгоритм пошуку в ширину (BFS) та дозволяє досліджувати його роботу на графах різних видів.

## Можливості програми

- робота зі звичайним неорієнтованим графом;
- робота з орієнтованим графом;
- робота з деревом;
- візуалізація процесу BFS;
- вибір початкової та цільової вершин;
- обхід суміжних вершин за зростанням або спаданням номерів;
- редагування структури графа;
- додавання та видалення вершин, ребер і дуг;
- відновлення знайденого шляху;
- відображення кількості розкритих вершин та ітерацій пошуку.

## Використані технології

- Python
- Tkinter

## Запуск програми 
python main.py
